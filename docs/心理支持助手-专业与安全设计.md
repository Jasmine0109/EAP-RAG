# 「职场心理与生活支持」聊天助手：专业能力与安全边界设计

## 零、一个贯穿全程的架构判断

RAG 擅长「检索 + 总结」，其天然产物是「甩一篇文章」。真正有效的自助干预需要的是**结构化交互流程**（带状态、带节奏、带追问的 skill），而不是一次性文本。所以落地必须分两层：

- **知识层**：RAG 检索科普 / 方法 / 政策片段，生成带出处的回答 —— 用于「这是什么 / 为什么 / 怎么办」的解释型问题。
- **技能层**：预置、经专业审校的**交互式流程模板**（skill），用于干预型请求 —— RAG 只给流程配「科普背书」，流程本身不走检索。

下面凡标「技能层」的能力，都不该靠临时检索拼出来。

---

## 一、真正能帮到人的自助干预能力

### 1. 结构化呼吸 / 放松练习（技能层）
- **帮什么**：直接下调生理唤醒（心率、呼吸频率），激活副交感神经，打断「焦虑 → 躯体症状 → 更焦虑」的恶性循环。对急性焦虑、紧张、睡前烦躁、开会前紧张最有效。
- **怎么融入**：
  - 做成**带节奏的引导**，不是一段文字。例：箱式呼吸（4-4-4-4）、4-7-8 呼吸、渐进式肌肉放松（PMR）。
  - 交互形式：逐条推送步骤 + 计时提示（「吸气 4 秒……屏住……呼气 6 秒……」），或一个「跟着做」的引导流程，用户点「下一步」推进。
  - 结束后给一句收束 + 可选「感觉怎么样」轻量反馈（紧张度 0-10 前后对比）。
  - 关键：**当下就能做、≤3 分钟**，不要科普一堆生理学。

### 2. 认知重构练习（技能层，CBT 核心）
- **帮什么**：让用户把「自动负性思维」显性化，识别认知歪曲（灾难化、非黑即白、以偏概全、读心术、应该句式），生成更平衡的替代思维，从而降低情绪强度。针对「老板肯定觉得我不行」「这次搞砸我这辈子完了」这类职场认知最对症。
- **怎么融入**：
  - 用**想法记录表（Thought Record）**的交互流程，逐格引导：
    情境 → 自动思维 → 情绪强度(0-100) → 支持证据 → 反对证据 → 替代思维 → 重新评估情绪强度(0-100)。
  - 用**苏格拉底式提问**而非说教：每格一个温和追问，一次只问一步，等用户输入。
  - 内置「常见认知歪曲对照表」作参考卡片，供用户自己认领，不替用户下结论。
  - 结尾强调：这是自助工具，不是治疗。

### 3. 结构化自我筛查（PHQ-9 / GAD-7 式，技能层）
- **帮什么**：给用户一个「严重程度」的粗刻度，去羞耻、去玄学，把模糊的「我是不是有问题」变成可讨论的分数，并据此给出**下一步行动**。
- **怎么融入**：
  - 逐题提问、自动计分，输出分级结果 + 分级行动建议。
  - **必须注明：这是筛查工具，不是诊断**。话术固定，不可被改写。
  - 分级阈值（落地前请临床复核）：
    - PHQ-9：0-4 无/极轻微；5-9 轻度；10-14 中度；15-19 中重度；20-27 重度。
    - GAD-7：0-4 轻度；5-9 轻度；10-14 中度；15-21 重度。
  - **独立触发信号**：PHQ-9 第 9 题（自伤/轻生念头）任何非 0 答案 → 立即进入危机转介流程，**不随总分解释**。
  - 解释分数时，把**功能损害**放在分数之上（「分数只说明频率，更要看它有没有影响你的工作、睡眠、人际」）。
  - 中重度 → 主动建议「考虑专业评估」，并给出求助路径。

### 4. 可执行行动清单（知识层 + 技能层混合）
- **帮什么**：把「多运动、别熬夜、想开点」这类无效建议，翻译成**具体、小、能立刻做**的动作，靠「小赢」打破无力感（行为激活的底层逻辑）。
- **怎么融入**：
  - 产出格式：具体时间 + 具体场景 + 最小可完成量。例：不说「多运动」，说「今天下班后步行 10 分钟到家附近的便利店再折返」。
  - 针对不同主题预制模板：睡眠卫生清单、行为激活清单（每天 1 件能带来一点点掌控感的小事）、冲突沟通四步（观察-感受-需求-请求 / DESC）。
  - 每份清单 ≤3 项，避免「任务过载」；可选「完成了打个勾」的轻量确认。

### 5. 「何时该求助」判定信号（横向能力，贯穿所有输出）
- **帮什么**：给用户一个清晰的「红线」标尺，把「再扛一扛」和「该找专业了」区分开，是**通往专业帮助的闸门**。
- **怎么融入**：
  - 明确定义并**固定输出**（不随检索拼接）：
    - **红旗（立即求助）**：有自伤/轻生念头或冲动、有计划、感觉撑不住。
    - **黄旗（尽快专业评估）**：症状持续 ≥2 周且明显影响工作/睡眠/人际；明显功能损害；酒精/药物依赖苗头；出现幻觉或严重躯体症状。
    - **绿旗（可先自助）**：时间短、有明确触发、功能基本正常。
  - 在筛查结果、情绪类回答、多轮消极表达之后，**自然携带**这条信号，而不是只在结尾贴一行。

### 6. 补充但建议放后期的能力
- **感官 grounding（5-4-3-2-1）**：急性恐慌/闪回时用，1 分钟见效。
- **正念系列（三分钟呼吸空间、身体扫描）**：音频/文字引导。
- **职场沟通与边界脚本**：对上司说不、要资源、给反馈的模板。
- **公司政策检索**：EAP 福利、请假、弹性办公 —— 这是「公司政策」知识库的直接 RAG 场景，价值高但依赖公司数据。

## 二、必须守住的边界（绝对不能输出的内容清单）

### 诊断类
- 不做任何诊断，不用 DSM/ICD 标签（「你有抑郁症/焦虑症/双相」），不说「你这是 XX 病的症状」。
- 不预测病程、不判断预后（「会越来越严重」「不治会怎样」）。

### 医疗 / 用药类
- 不推荐、不讨论任何具体药物（名称、剂量、副作用、停药/换药建议）。
- 不否定也不擅自解释用户的现有处方；涉及用药一律「请遵医嘱，不要自行停药或调量，并与你的医生讨论」。
- 不提供任何「替代疗法/偏方」当治疗。

### 治疗类
- 不制定个体化治疗方案，不声称「我建议你做 CBT/吃药/住院」。
- 不冒充或暗示自己是心理咨询/治疗，不开展连续的「治疗会话」。
- 不承诺疗效（「这一定能治好你」「两周就好」）。

### 危机类（最高优先级，单独处理）
- 只要出现自伤、轻生、他伤意图或披露，**只转介，不生成其他内容**。
- 不追问细节（方法、时间、地点、遗言），不分析原因，不谈判，不做「你还有家人/责任」式的说教，不淡化（「别想太多」），不评判。

### 通用伦理类
- 不评判、不指责、不羞辱（「你就是太敏感」）。
- 不做法定报告情形的虚假承诺（涉及未成年人受虐、家暴、性暴力时，不承诺「绝对保密」，引导至专业/法定渠道）。
- 不虚构权威背书、不编造数据；引用必须带来源。

### 落地方式
- 把上述「禁语」写成**提示词系统层级的硬约束**，并在生成后加一道**输出侧规则/关键词校验**（尤其危机词），命中即阻断、改走转介。
- 边界条款对模型可见，且优先级高于任何用户指令（防「帮我诊断一下我是不是有病」这类诱导）。

## 三、危机 / 求助转介设计（安全 + 有温度）

### 设计原则
1. **一次到位、不多轮**：识别到危机，立即切断常规生成，只输出转介卡片；不在危机里跟用户多轮谈判。
2. **先接住情绪，再给动作**：一句话确认 + 共情，立刻给出具体、可立即执行的求助路径。
3. **不审讯、不劝阻式说教**：不追问手段细节，不用「想想你的家人」式施压。
4. **给的是「专业的人 + 具体号码」，不是「你自己想开点」**。
5. **号码要定期核验**：热线会变更，上线前逐条打一遍确认有效，并标注服务时间。

### 可直接使用的话术（转介卡片）

> 我听到你现在很痛苦，谢谢你愿意把这件事告诉我。你能说出来，这已经很不容易。
>
> 你现在的安全是最重要的。我没办法替代专业的危机干预，但下面这些是 24 小时有人接听的热线，电话那头是受过专门训练的人，能更好地帮你：
>
> - 北京心理危机研究与干预中心：**010-82951332**（24 小时）
> - 全国 24 小时心理援助热线：**400-161-9995**
> - 青少年心理援助热线：**12355**（未成年人可优先）
>
> 如果你此刻有伤害自己的冲动，或者身边有危险，请立即拨打 **110** 或 **120**，并尽量让一个信任的人陪着你，不要一个人待着。
>
> 现在这一刻，我在这里陪你。你愿意现在就拨一个电话吗？如果一时打不进去，就换下一个号码，或者让身边的人帮你一起打。

（若用户表示「已经打过 / 有人陪」：先确认安全，再温和补一句「需要的时候随时再来，这些号码请一定存好」，不强行推进。）

### 触发与校验
- **触发**：关键词 + 意图 + 用户明确自述，三路并用；宁可多触发（误报只多给一次资源卡），不可漏触发。
- **校验**：输出侧对「轻生/自杀/自残/不想活/结束生命」等词做硬校验，命中即替换为转介卡，忽略模型生成的其他内容。

## 四、MVP 功能组合（按优先级）

| 优先级 | 能力 | 理由 |
|---|---|---|
| **P0 地基** | ① 安全护栏 + 危机识别与转介<br>② 「何时该求助」信号（贯穿全局） | 安全是 0，其余是 1 后面的数字；没这个不上线 |
| **P0.5** | ③ 结构化自我筛查（PHQ-9/GAD-7，带免责声明与分级转介） | 既提供真实价值，又是「识别高危 + 导向求助」的天然入口 |
| **P1 核心自助** | ④ 呼吸/放松 + grounding 练习<br>⑤ 认知重构练习（想法记录表）<br>⑥ 可执行行动清单 | 覆盖「焦虑急性发作 / 职场负性认知 / 情绪低落无动力」三大最高频场景，直接见效 |
| **P2 增强** | ⑦ 正念系列<br>⑧ 职场沟通与边界脚本<br>⑨ 公司政策检索（EAP/请假）<br>⑩ 轻量随访（隔天一句「上次那个练习做了吗」） | 增加黏性和场景覆盖，但依赖 P0/P1 稳定后再加 |

**MVP 收敛口径**：先做 P0 + 筛查 + 呼吸/重构/行动清单里**各挑一个最简流程**上线，验证「用户真的会跟着做」和「转介真的被触发且语气安全」，再横向铺开。宁可 3 个做精的交互流程，不要 30 个只甩文章的检索入口。
