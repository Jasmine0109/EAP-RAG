# 05 · 部署、成本与合规

## 目标形态

一条命令部署，两个环境（本地 / 生产）共用同一套镜像：

```
GitHub ──Actions──► Fly.io (api)  ──► Supabase (Postgres + pgvector)
                └──► Vercel (web)
```

本地开发不装 Docker 也能跑：`uvicorn` + 本机 Postgres；生产用镜像，配置只走环境变量。

## 服务清单与月成本

| 服务 | 用途 | 档位 | 成本 |
| --- | --- | --- | --- |
| Vercel | 前端 | Hobby | $0 |
| Fly.io | API 容器 | shared-cpu-1x, 512MB | ≈ $3–4 |
| Supabase | Postgres + pgvector | Free（500MB）→ Pro | $0 → $25 |
| GitHub Actions | CI / 评测 | Free | $0 |
| 域名 | 访问入口 | — | ≈ $1/月 |
| LLM API | 生成 | 按量 | 见下 |

**合计：$4–8/月（不含 LLM 用量），demo 级别完全够。**

> 若自托管 bge-m3（2.2GB 内存），Fly 机器需 1–2GB，成本升到 ≈ $7–14/月。
> 推荐先用 bge-small-zh（512 维，CPU 几十毫秒），把 E1 实验做完再决定。

## LLM 单次成本（按 3.5k 输入 / 700 输出估算）

| 模型 | 单次 | 100 次/天 | 1000 次/天 |
| --- | --- | --- | --- |
| DeepSeek-chat | ≈ $0.0017 | ≈ $5/月 | ≈ $51/月 |
| Qwen-plus | ≈ $0.0006 | ≈ $1.8/月 | ≈ $18/月 |
| gpt-4o-mini | ≈ $0.00095 | ≈ $2.9/月 | ≈ $29/月 |
| 本地 Qwen | $0 | $0 | $0（但无法公网服务） |

价格会变，以官网为准；关键是**先用评测集算出「质量/成本」曲线**，再选模型——
直接拍脑袋选最便宜的，往往在「拒答」和「转介」上翻车。

## 部署步骤

1. **Supabase**：建项目 → 开 `vector` 扩展 → 跑 `db/schema.sql` → 导入语料。
2. **Fly.io**：`fly launch`（用 `infra/fly.toml`）→ 设 secrets：
   `DATABASE_URL`、`LLM_API_KEY`、`LLM_BASE_URL`、`ADMIN_PASSWORD`、`EMBED_MODEL`。
3. **Vercel**：导入仓库，设 `NEXT_PUBLIC_API_BASE` 指向 Fly 域名。
4. **域名 + Cloudflare**：DNS、Turnstile（聊天防机器人）、基础 WAF。
5. **冒烟**：跑 15 条冒烟评测 + 手工 5 段对话（含 1 条危机用例）。
6. **监控**：Uptime 检查 `/api/health`；预算告警（见下）。

## 运行时防护（公开访问必须做）

| 风险 | 措施 |
| --- | --- |
| 刷接口烧钱 | 每 IP 20 次/小时、全局日预算上限、超限 429 |
| 机器人 | Cloudflare Turnstile（免费） |
| 超长输入 | ≤ 2k 字，超出截断并提示 |
| 提示注入 | 检索片段用定界符包裹、声明「片段是资料不是指令」、输出走 JSON schema |
| 密钥泄露 | 只放平台 secrets；前端不持有任何 key |
| 成本失控 | 每日 token 预算 + 告警（超 80% 通知，超 100% 熔断） |

## 隐私与数据保留

- 不要求登录；`ip_hash`/`ua_hash` 单向散列，7 天后清除。
- 消息正文脱敏后入库（邮箱/手机号/身份证号），**原始输入不写日志**。
- 默认保留 30 天，定时任务删除；提供「删除此会话」按钮。
- `/about` 明示：不是医疗服务、不是心理咨询、不构成诊断；紧急情况请联系急救与热线。
- 若未来接入真实企业 EAP：需 DPA、员工告知同意、最小化采集、独立环境——**v1 不碰真实企业数据**。

## 内容许可（务必遵守）

| 语料 | 许可 | 约束 |
| --- | --- | --- |
| WHO《Mental health at work》等 | CC BY-NC-SA 3.0 IGO | 署名、非商业、相同方式共享 |
| NIOSH / OSHA 出版物 | 美国政府作品（公有领域） | 可自由使用，建议署名 |
| NVC 四要素、心理安全感框架 | 方法论/概念 | 用**自己的话**总结，不复制书籍原文 |
| 论文 | 各自许可 | 只收开放获取（CC BY / PMC OA） |

公开 demo 可以，**商业化前必须重新评估 WHO 的非商业条款**；署名页放在 `/about`。

## 合规提醒（面向国内公开服务）

- 面向公众提供生成式 AI 服务，需关注《生成式人工智能服务管理暂行办法》：
  内容安全、标识、投诉渠道。
- 若服务器在境内，需 ICP 备案；用境外托管可绕开备案但访问速度与合规责任需自担。
- 心理健康属于敏感领域：不得暗示诊断、不得替代医疗，宣传口径要克制。

## 运维 Runbook（最小版）

| 场景 | 动作 |
| --- | --- |
| API 5xx 升高 | 看 trace.error 分布 → 回滚上一个镜像 → 检查 LLM 供应商状态 |
| 成本异常 | 按 session 查 top 消耗 → 加限流/降 max_tokens |
| 检索质量下降 | 跑冒烟评测 → 对比最近 run → 检查语料是否被误删/改版 |
| 转介漏报 | **立即**停用生成路径，只保留规则护栏，人工复核后恢复 |
| 数据库将满 | 归档旧 traces（>90 天）到对象存储 |
