# 数据 pipeline 设计 v0.1

> 目标：从白名单源抓内容 → 清洗成干净文本 → 切块 + 向量化 → 存进云端，供 App 检索。
> 核心结论：**本地只用来开发，数据最终在云端；规模几百 MB，不用 PySpark。**

## 1. 先回答三个问题

### ① 为什么要先在 local？在 local 到底做什么？

**local = 开发机（你的 Mac），cloud = 数据的最终家。代码只有一份。**

local 不是目的，而是因为开发期要**改 20 次、看 20 次输出、修 20 个 bug**：
- 本地跑一次几秒钟，错误当场弹出来；云端每次要上传、等待、看日志，还按分钟计费。
- 爬虫和清洗有大量边界情况（乱 HTML、跳转、乱码），你会在前 10 篇文章上全部踩一遍。
- 本地能直接打开文件、查数据库行，确认"切块对不对、来源记没记上"。

**跑通后**，把"存储地址"从本地 SQLite 换成云端，跑同一份代码——这就是"上云"。不存在"本地版 / 云端版"两套。

类比：**厨师先在家里试菜（快、免费、能尝），再搬到餐厅营业（同一个菜谱）。**

### ② 不能把爬下来的数据直接放云端吗？

能。但你会**一边付云费一边 debug**，而且慢。正确顺序是：
先拿 **每个源 5 篇** 在本地把 pipeline 调对 → 全量跑到云端。这不矛盾，只是先后。

### ③ 用 PySpark 清洗？

**不用。** PySpark 是给 TB 级（万亿字节）数据、几十台机器的集群用的。
我们的语料：几千篇文章 ≈ 几百 MB，**单机 Python 几秒到几分钟跑完**。

| 数据量 | 用什么 |
| --- | --- |
| < 10 GB | 单机 Python（**我们现在在这里**） |
| 10 GB – 1 TB | Polars / DuckDB / Dask（单机大内存） |
| > 1 TB | 才需要 Spark 集群 |

用 Spark 处理几百 MB，就像用火车运一个行李箱：写 10 倍代码、烧集群钱，却不更快。

## 2. pipeline：4 个阶段（每个独立、可重跑、幂等）

```
① crawl        抓取白名单 URL → corpus/raw/（原始 HTML）
② extract+clean HTML→纯文本，去导航/广告/乱码，去重 → corpus/processed/*.jsonl
③ chunk+embed  切块（带标题/来源/许可元数据）→ 向量化
④ load         写入云端：块+向量进 Postgres(pgvector)，原始 HTML 备份进对象存储
```

每个阶段是独立脚本，能单独重跑；重复跑不产生重复数据（按 URL/sha256 幂等）。

## 3. 存储：冷热分开

| 类型 | 放哪 | 为什么 |
| --- | --- | --- |
| 冷（原始 HTML、清洗后 jsonl） | 对象存储 S3 / R2 | 大、不常读、便宜 |
| 热（块 + 向量，App 要查） | Postgres + pgvector | 要索引、要快 |

小规模可以先都放 Postgres，R2 只存原始 HTML 作备份（重新清洗时不用再爬）。

## 4. 云端选型（我的推荐：不用买 AWS）

| 用途 | 推荐 | 成本 |
| --- | --- | --- |
| 对象存储 | Cloudflare R2 | 免费 10GB，无下载流量费 |
| 数据库 | Supabase（Postgres + pgvector） | 免费 500MB |
| 后端 / 跑 pipeline | Fly.io | ≈ $3–7/月 |

**为什么不推荐直接上 AWS**：功能全但学习曲线陡、账单容易踩坑（忘关实例、流量费）。
**如果你就是想用 AWS**（比如为了简历/学 AWS），最小组合是：S3 + RDS(Postgres+pgvector) + 一个 ECS 任务跑 pipeline，**并务必设账单告警**。

结论：先按 R2 + Supabase + Fly 走，省心省钱；以后要 AWS 随时能迁（S3 兼容）。

## 6. 本地开发你要做的事（具体清单）

1. 写 `crawl`：抓上面 3–4 个源各 5 篇 → `corpus/raw/`
2. 写 `extract+clean`：HTML → 纯文本 → `corpus/processed/*.jsonl`（附来源/许可/URL/时间）
3. 写 `chunk+embed`：切块 + 向量 → 本地 SQLite（先验证）
4. 人工抽查：文本干净吗？切块边界对不对？元数据齐不齐？
5. 全绿 → 存储地址换成云端 → 全量跑。
