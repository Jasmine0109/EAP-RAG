# 项目地图

一页看懂代码在哪、数据怎么流、要改东西该动哪个文件。

## 数据流

```
                ┌────────────── src/rag/ingest.py ──────────────┐
 data/raw/*.md ─► iter_files ─► chunk_document ─► list[Chunk]     │
                └───────────────────────┬────────────────────────┘
                                        │
                     src/rag/embed.py ──▼── HashingEmbedder.embed
                                        │  (n, dim) float32, L2 归一
                     src/rag/store.py ──▼── Store.replace_doc
                                        │  chunks + vectors → SQLite
                                        │
 问题 ──► embed ──► Store.search(余弦) ──► list[Hit]
                                        │
                     src/rag/generate.py▼── build_messages → LLMClient.chat
                                        │  失败/--offline → offline_answer
                                        ▼
                                     Answer(text, hits, mode)
```

## 模块职责

| 文件 | 职责 | 改动时注意 |
| --- | --- | --- |
| `config.py` | 环境变量 → 不可变 `Config`，启动即校验 | 新增参数要给默认值并写进 `.env.example` |
| `types.py` | `Chunk` / `Hit` / `Answer` / `IngestStats` | 极简 dataclass，别塞业务逻辑 |
| `ingest.py` | 找文件、按段落切块、跟踪标题 | 切块改动必须补测试：不超长、重叠、超长段落 |
| `embed.py` | 向量化接口 + 哈希占位实现 | 换模型只改 `build_embedder`；维度变要重建索引 |
| `store.py` | SQLite 存储、幂等写入、暴力检索 | 换向量库实现 `replace_doc/search/count/stats/reset` |
| `generate.py` | prompt 拼装、OpenAI 兼容调用、离线兜底 | 只依赖标准库 urllib |
| `pipeline.py` | 编排三个动作：ingest / retrieve / ask | 业务逻辑集中在这里，CLI 只负责解析参数和打印 |
| `cli.py` | 命令行 | 错误信息要说人话，并给出下一步命令 |

## 索引文件

`data/index/index.sqlite3`，三张表：

- `chunks`：块正文 + 元信息（`doc_id`、`source`、`idx`、`heading`）。
- `vectors`：`chunk_rowid → float32 BLOB`，与 `chunks` 一一对应。
- `meta`：目前只存 `dim`，用来发现"换了模型没重建索引"。

`replace_doc(doc_id, ...)` 先删同 `doc_id` 的旧块再插入，所以重复 ingest 是幂等的。

## 常见改动怎么下手

| 想做的事 | 动哪里 |
| --- | --- |
| 支持 PDF / docx | `ingest.iter_files` 前加转换，落到 `data/processed/` |
| 换嵌入模型 | `embed.build_embedder` + `RAG_EMBED_DIM` + 重建索引 |
| 加 rerank | `pipeline.retrieve` 之后加一步重排，`ask` 前生效 |
| 换向量库 | 新类实现 `Store` 五个方法，注入 `Rag(store=...)` |
| 改 prompt | `generate.SYSTEM_PROMPT` / `build_messages` |
| 加评测 | 新建 `tests/` 或 `eval/`，固定问题 + 期望片段，跑 `store.search` 算召回 |
