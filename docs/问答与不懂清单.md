## 二、你表示"不懂"的概念（一句话 + 出处）

| 概念 | 一句话人话 | 出处 |
| --- | --- | --- |
| Vercel | 放前端网页的托管服务，推代码自动上线，免费 | §4.1、§10.1 |
| Supabase | 托管 Postgres 数据库（含向量检索），免费 500MB | §4.3、§10.1 |
| Fly.io | 放后端程序的托管服务，按机器规格收费，约 $3/月 | §4.2、§10.1 |
| token / 成本 | 调用模型按输入+输出字数计费，每次记进 traces 表 | §7.1、§5.7 |
| embedding / 向量 | 把文本变成一串数字，意思越近数字越像，检索就是比数字 | §0、§4.4 |
| LLM 哪个好 | 用同一套评测用例跑 E4 实验对比质量/成本 | §9.3 |
| Vector DB | 存向量的数据库；本项目用 Postgres 的插件 pgvector，不单独买 | §4.3、§3.4-D1 |
| log / debug | 每次请求记一条 trace，后台按字段排查 | §7 |
| 云端 vs 本地 | 本地只用来开发（快、不烧钱），交付物是云端 URL | §10 |
