# MVP 设计 v0.2 —— 最小可行产品

> 一句话：一个「**先问清楚发生了什么 → 再给你一个能做的微行动和求助信号**」的职场心理支持助手。
> 和科普问答机器人的区别：**先懂你，再帮你，而不是甩一篇文章。**

## 0. 对话怎么走：先搞懂原因，再给帮助

**最重要的一条：没搞懂「发生了什么」，就不给建议。**

| 情况 | 助手做什么 |
| --- | --- |
| 原因清楚（用户直接说了） | 直接给回答卡 |
| 原因笼统（只说「压力大」没讲为什么） | 共情 + **只问一个开放问题**，不给建议 |
| 追问后仍不清楚 | 再问一次（最多 2 次），仍不清楚就给「最可能有用」的通用帮助，并邀请继续补充 |

不是「一次问 5 个问题」（那是审问），而是**一次只问一句**，把对话往前推。

## 1. 回答卡（固定 5 段）

```
① 共情一句      承认感受，不评判、不教育（"听起来你在被睡不好拖累"）
② 核心建议 2-3 条  带 [n] 引用
③ 一个微行动 ⚡  "现在就做"，1-3 分钟，可执行
④ 何时求助 ⚠️   红/黄旗信号（贯穿，不只在结尾贴一行）
⑤ 来源 [1][2]   可点开看原文
   ↓ 微行动下面两个按钮：有用 / 没用（记住效果，为"越用越懂你"打基础）
```

## 3. 三个特色点（最小但有效）

| 特色 | 为什么这是差异 |
| --- | --- |
| **共情接住** | 用户是来倾诉的，先被理解，建议才听得进去；直接甩科普只会让人更堵 |
| **微行动 + 效果回环** | 精疲力竭的人要的是"现在能做的一小步"，不是 500 字；"有用/没用"让它越用越懂你 |
| **何时求助贯穿 + 危机整屏转介** | 安全是底线；"什么时候该找专业帮助"本身是最有价值的一条信息 |

## 4. 三个示例

**A｜压力 + 失眠（两轮，先问清楚再帮）**
> 第 1 轮 用户："最近压力大，晚上睡不着，白天没精神"
> 助手："听起来挺累的。最近是工作上遇到了什么，还是生活里的事？愿意多说一点吗？"（共情 + 追问，不给建议）
> 第 2 轮 用户："主要是老板总在下班前派活，天天干到十一二点"
> 助手：共情 → ① 把"时间成本"摆到台面沟通 ② 睡前写"最担心的一件事" → 微行动（4-7-8 呼吸）→ ⚠️ 持续 2 周建议求助 → 来源

**B｜和老板关系紧张**
> 输入："和老板关系紧张，不知道怎么办"
> 输出：共情 → ① 把"事实"和"感受"分开 ② 准备一次"我需要什么"的沟通 → 微行动（一段可复制的话术模板）→ 求助信号 → 来源

**C｜危机**
> 输入："活着没意思，想解脱"
> 输出：**不生成任何建议**，整屏危机卡 + 热线。

## 5. 危机识别（分级，宁多勿漏）

- 触发：**关键词 + 意图 + 明确自述**三路并用，宁可多触发不可漏触发。
- 输出侧硬校验：命中「轻生/自杀/自残/不想活/结束生命」→ 一律替换成转介卡。
- 话术原则：一次到位、不审讯、不说教、给"专业的人 + 具体号码"。

## 6. MVP 范围

**做**：聊天页 + 回答卡（共情/建议/微行动/何时求助/来源）+ 微行动反馈 + 危机整屏转介；本地跑通。
**不做**（往后放，见下）：登录、多轮记忆、后台、评测平台、云端部署。

## 7. V1 预留（多方建议，明确推迟）

意图分诊菜单、情绪结构化卡、跨会话记忆 + 进展线、主动回访、
结构化筛查（PHQ-9/GAD-7，注明"筛查不是诊断"）、呼吸引导流程、
认知重构想法记录表、职场话术库、公司政策检索。

> 原则：MVP 先把「共情 + 微行动 + 何时求助 + 危机」四个点做精，再铺 V1 的交互流程。
